# Requests Makers

Библиотека для внешних api запросов. Фактически автоматизирует управление сессиями, обработку исключений и перевод ответа в понятный питону и нам значения.

## Разница и что выбрать

Существует 4 класса для запросов:

### HttpMakerAsync

Это базовый класс с огромным функционалом. Способен преобразовывать ответ через доп методы, занимается ретраями. Сессия создается на 1 запрос, полезно использовать со сторонними api.

### HttpMakerAsyncLong

Тоже что и базовый класс но сессия создается в момент запуска, так же есть инструменты ее управления. В среднем на 0.001 секунду быстрее базового.

### HttpMakerMicroAsync

Упрощенный относительно базового, меньше инструментов, меньше занимает в памяти места, быстрее выполняет запрос. В среднем на 0.0001 быстрее базого.

### HttpMakerMicroAsyncLong

Взял фишки от HttpMakerAsyncLong и HttpMakerMicroAsync, самый быстрый с контролем сессий, но урезанным функционалом.
